# Nimpol Chronicles Architecture

This folder contains the evolving architectural documentation for Nimpol Chronicles.

The documents describe the intended design of the system. They are architectural references rather than implementation checklists.

As the project evolves, these documents are updated before major implementation changes whenever practical.

When implementing features:

- Treat these documents as architectural intent.
- Prefer extending the existing architecture over introducting parallel designs.
- If implementation constraints require deviating from the architecture, explain the tradeoffs before making changes.
